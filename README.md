# mnist-digits

Сеть из ролика 3Blue1Brown «But what is a Neural Network?»: распознавание рукописных цифр MNIST. Архитектура 784 → 16 → 16 → 10.

Первый прогон уже сделан: 10 эпох, на отложенных 10 000 картинках верно 92,4 %. Запись эксперимента: [experiment.md](experiment.md).

## Цель

Посмотреть, из чего состоит MNIST, обучить сеть 784 → 16 → 16 → 10 на 60 000 картинках и увидеть веса. Экзамен идёт по другим 10 000 картинкам, которые в обновление весов не входят. Страница весов читает снимок, который пишет `train.py`.

## Стек

- Язык: Python 3
- Сеть: PyTorch (CPU-сборка)
- Картинки: torchvision, датасет MNIST
- Сетка примеров: matplotlib
- Страница весов: `http.server` из стандартной библиотеки, без отдельного веб-фреймворка

## Установка

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install matplotlib
```

CPU-сборки достаточно: в сети около 13 000 параметров. Полная сборка с CUDA на Windows весит гигабайты и здесь не нужна.

Каталоги `data/` и `output/` в git не входят. В первом лежат скачанные картинки, во втором отчёт, сетка примеров и снимок весов после прогона.

## Запуск

Из папки проекта.

Разбор данных, без обучения:

```powershell
python explore_data.py
```

Пишет `output/report.txt` и `output/samples.png`.

Страница весов, тоже без обучения:

```powershell
python web.py
```

Открыть http://127.0.0.1:8765/ . Если в `output/checkpoint.pt` уже есть снимок прогона, страница показывает его. Если файла нет, на экране случайные начальные веса. Остановить сервер: Ctrl+C.

Повторить обучение:

```powershell
python train.py
```

Если в это время открыта страница, она обновляется примерно каждые 50 батчей и в конце каждой эпохи.
